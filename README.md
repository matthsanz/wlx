# WLX – Playlist & Watch Later Exporter for YouTube™

Website of WLX, an add-on for Firefox and Microsoft Edge that exports your YouTube Watch Later list and playlists to a spreadsheet.

- Website: https://matthsanz.github.io/wlx/
- Firefox Add-ons: https://addons.mozilla.org/firefox/addon/wlx-playlist-exporter/
- Microsoft Edge Add-ons: https://microsoftedge.microsoft.com/addons/detail/cejnaobnjbnkbiihgnaepegdfenlhhhp
- Support: wlx.exporter@gmail.com

This repository holds only the website. The add-on's source code is not published here.
